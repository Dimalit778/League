Screen Transitions

Currently no transitions are configured — expo-router uses its default. Here's what we'd set per screen type.

DETAIL SCREENS — match, member profile, edit-league

iOS

slide_from_right

Swipe back from left edge to dismiss. Standard push navigation — same as Settings.app, Mail, etc.

Android

slide_from_right

Predictive back gesture support. Material 3 uses right-to-left push for navigation.

OVERLAY SCREENS — Settings, My Leagues (picker/config UI)

iOS

presentation: modal

Slides up from bottom. Swipe down to dismiss. Feels like a sheet — same as iOS Share Sheet, App Store product pages.

Android

slide_from_bottom

Slides up from bottom. Standard for secondary/overlay flows in Material 3.

AUTH SCREENS — sign in, sign up, verify, reset

iOS

fade within flow, slide_from_right for steps

No swipe-back between auth steps. Steps inside auth flow slide right (sign in → verify email).

Android

fade within flow, slide_from_right for steps

Same pattern. No history-based gestures within auth.

TAB ROOT SCREEN — (tabs)

animation: none on both platforms

The tab bar handles its own switching. The stack entry for the tab root should never animate.
