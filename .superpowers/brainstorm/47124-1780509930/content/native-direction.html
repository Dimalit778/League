What does "native" mean to you?

The app currently uses custom fonts (Nunito/Teko), a fully custom tab bar, and app-specific colors. "Native" can mean different things — pick the direction that resonates most.

A

System fonts + platform conventions

Switch to SF Pro on iOS and Roboto on Android. Use native-style navigation bars, large titles, proper bottom tabs. The app feels like it was built with Apple/Google's HIG in mind.

Highest impact on "feel". Most changes are in typography and nav chrome.

B

Keep custom fonts, improve native patterns

Keep the Nunito font personality but fix the things that feel off: better shadows, proper safe areas, haptic feedback, platform-specific button shapes, native alerts/action sheets.

Preserves brand identity. Targets subtle UX issues that break the native illusion.

C

Platform-split design (iOS looks iOS, Android looks Android)

Explicit platform branching: iOS gets large titles, sheet modals, SF Symbols-style icons, spring animations. Android gets Material 3 design, ripple effects, FAB patterns, Roboto.

Most "native" result, but more code to maintain. Each platform feels fully at home.
