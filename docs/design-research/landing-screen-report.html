Design research · 6 August 2026 · iOS/Android · Hebrew and English

Champo landing screen

A research-backed adaptation of the supplied premium football onboarding concept into a focused, accessible first-run screen for Champo.

SynthesisInputReferencesComparisonRecommendationsExperience

Title and scope

Inference

Target job: help a football fan understand Champo's value—predict matches, compete with friends, rise in a league—then enter authentication without setup decisions or permissions.

Audience and constraints: mobile-first football fans; RTL and LTR; existing Expo React Native stack; existing navy/gold visual system and stadium background; authentication currently begins on the next route.

Success criteria: value understood at a glance, one dominant action, a clear sign-in path for returning users, no permission prompts, readable on small phones, and no loss of existing routing behavior.

Executive synthesis

Observed fact

The reference sells the game loop

Prediction and leaderboard cards communicate the product more concretely than a generic trophy image. The CTA appears only after this value preview.

Recommendation

Use one-screen progressive disclosure

Show a compact live-looking product preview, one benefit statement, one primary CTA, and a secondary sign-in action. Avoid a five-page carousel when each page would repeat the same core promise.

Recommendation

Adapt, do not copy

Keep Champo's existing stadium artwork and brand palette, but rebuild the preview from native components. This stays responsive, localizable, testable, and visually original.

Inference

Main risk

The supplied design is visually rich but dense. On smaller phones, fixed proportions could push the CTA below the fold or make Hebrew text too small. Responsive height bands are required.

Input analysis

Observed fact

Information architecture

Brand → atmospheric stadium → prediction and leaderboard preview → headline and supporting copy → large primary CTA → returning-user sign-in → five pagination dots.

Observed fact

Visual language

Deep navy field, white typography, amber-gold emphasis, glassy bordered cards, stadium floodlights, and high-contrast button. The composition signals premium competition and match-night energy.

Inference

Likely journey position

This is the first slide of a multi-page onboarding carousel. For Champo's current route structure, the dots would imply unavailable pages and should not be retained unless those pages are implemented.

Recommendation

Transferable parts

Preserve the value preview, headline hierarchy, navy/gold palette, CTA dominance, and explicit returning-user affordance. Replace trademarked club imagery and portraits with neutral native UI.

Risks and anti-patterns

Recommendation

Do not encode text in imagery

Native text preserves Hebrew/English localization, Dynamic Type behavior, accessibility labels and future copy changes.

Recommendation

Do not rely on gold alone

Use labels, weight, borders and layout in addition to color. Keep white-on-navy copy and dark-on-gold CTA above accessible contrast targets.

Recommendation

Avoid fake interaction

Remove carousel dots unless swiping exists. Preview cards should be marked as non-interactive and hidden from the accessibility tree when decorative.

Inference

Small-screen overflow

The premium composition can become cramped below roughly 700 logical pixels. The hero must shrink before the CTA and sign-in link do.

Recommendations

Proposed experience

Recommendation

Information architecture and states

Default: logo wordmark, two-card product preview, headline, support copy, primary CTA and sign-in text action. Compact-height: smaller preview and tighter gaps, with actions preserved. RTL/LTR: language-aware copy and row direction; numbers remain readable. Loading/error: none on landing because it uses bundled assets and local navigation.

Component guidance

Keep the existing `Screen`, `Button`, `Text`, `expo-image`, router and translation primitives. Construct preview cards with native `View`/`Text`, soft borders and shadows. Reuse the bundled stadium background; add a dark gradient overlay to guarantee text contrast.

Content guidance

Hebrew: “כל משחק הוא אתגר” / “חוזים תוצאות, מתחרים עם חברים ומטפסים בטבלה.” English: “Every match is a challenge” / “Predict scores, compete with friends, and climb the table.”

Accessibility

One combined brand label, decorative hero hidden from screen readers, CTA minimum 48pt high, secondary action exposed as a button/link, contrast independent of background crop, and layouts that tolerate larger text.

Analytics

Recommended future events: `landing_viewed`, `landing_get_started_tapped`, `landing_sign_in_tapped`, each with locale and device-height bucket; no personally identifying properties.

Open question

A later auth-screen redesign should confirm whether sign-up and sign-in still need separate route screens or can share the existing mode toggle. The landing implementation intentionally routes each audience to its matching mode.
