Champo on iPad

Scope: make the existing Expo app a credible universal iPhone/iPad release without replacing its familiar four-tab information architecture.

Synthesis

Keep the tabs

Recommendation. Four stable primary destinations fit Apple’s tab-bar model and do not justify a permanent sidebar yet.

Design for width, not device name

Source-reported claim. iPad windows can move between compact, intermediate and regular widths.

Protect readability

Recommendation. Center content and cap line/card width while allowing backgrounds and safe areas to fill the window.

Input analysis

Observed fact. ios.supportsTablet is already true and orientation is default.

Observed fact. Shared screens use max-width tokens from 384px through 896px and responsive horizontal padding.

Observed fact. The floating bottom tabs are capped at 720px, preventing excessive reach on wide iPads.

Inference. The main release risk is verification across resizable widths, RTL and Dynamic Type—not an absent tablet flag.

Reference set

Apple · Split views

Source-reported claim. Interfaces must remain useful at narrow, intermediate and regular widths.

Apple · Sidebars

Source-reported claim. Sidebars are valuable when space and hierarchy warrant them, and may adapt with width.

Apple · Tab bars

Source-reported claim. A tab bar is appropriate for persistent top-level destinations and should remain stable.

Apple · Typography

Source-reported claim. Dynamic Type should be tested on both iPhone and iPad, with layouts adapting around it.

React Navigation · Safe areas

Source-reported claim. Safe-area insets prevent controls and content from colliding with system UI.

Structural evidence

Recommendation. Wide background, bounded content, bounded navigation.

Recommendation. The same flow survives Split View without a navigation-mode switch.

Leaders and fast first run

Inference. Apple’s own adaptive navigation APIs are the reference leader: the navigation structure may change when width changes, but task continuity should not.

Recommendation. Champo’s fastest first run is identical on phone and tablet: authenticate, select a league, land on Home, then discover Matches, Leaderboard and Profile in the same fixed order.

Risks and proposed experience

Resize

Recommendation. Test full-screen portrait/landscape and narrow Split View; no clipped buttons, fixed widths or stale orientation assumptions.

Language

Recommendation. Exercise Hebrew RTL and English at every target width, including long labels.

Accessibility

Recommendation. Verify large Dynamic Type and keyboard/focus behavior where hardware keyboards are supported.

Store delivery

Recommendation. Confirm final IPA device family and provide required iPad screenshots before TestFlight/App Store review.
